# Contrato G0 — usuários, RBAC, artifact store, egress

Fonte única para backend, SDK e web. Decisões: ADR-006, ADR-007, ADR-012. Onde o backend divergir deste texto por motivo técnico, o backend vale e o desvio é registrado no ledger.

## 1. Autenticação e autorização

### Credenciais aceitas em `/api/v1/*` e `/v1/traces`

| Credencial | Cabeçalho | Projeto vem de | Poder |
|---|---|---|---|
| Chave de API | `Authorization: Bearer mx_<prefixo>_<segredo>` (ou `x-matrix-api-key`) | a própria chave | escopos `ingest`, `read`, `write` |
| Sessão de usuário | `Authorization: Bearer mxs_<token>` + `X-Matrix-Project: <project_id>` | o cabeçalho (o usuário precisa ser membro) | papel do usuário no projeto |

Sessão sem `X-Matrix-Project` só acessa rotas sem projeto (`/api/v1/auth/*`, `/api/v1/projects` lista/cria). `401` para credencial ausente/inválida/expirada (mensagem genérica, `WWW-Authenticate: Bearer`); `403` para papel/escopo insuficiente (`{"detail": "requires role member"}`); `404` quando o usuário não é membro do projeto pedido (não revela existência).

### Papéis → capacidades

`viewer < member < admin < owner`. Escopo da chave: `read` ≈ viewer, `write` ≈ member (inclui read), `ingest` só ingestão. Mapa mínimo:

| Rotas | Mínimo |
|---|---|
| `POST /v1/traces` | escopo `ingest` ou papel member |
| `GET` em `/api/v1/*` de dados (traces, sessões, stats, scores, prompts, datasets, experimentos, anotações, regras, alertas, avaliações online, artefatos, runs…) | viewer / `read` |
| `POST/PUT/PATCH/DELETE` de dados de trabalho (scores, prompts, datasets e itens, experimentos, anotações, runs, artefatos…) | member / `write` |
| Regras, avaliações online, mover label `production`, membros, chaves, hosts de saída, webhooks | admin (somente sessão; chave nunca é admin) |
| Apagar projeto, promover/rebaixar admin | owner |

Itens de módulos futuros declaram seu mínimo na própria fatia usando a mesma dependência.

### Dependência única (backend)

```python
# matrix_server/auth.py
class Role(IntEnum): VIEWER=1; MEMBER=2; ADMIN=3; OWNER=4
@dataclass(frozen=True)
class Principal:
    project_id: str
    kind: Literal["api_key", "user"]
    user_id: str | None
    role: Role              # para chave: VIEWER (read) ou MEMBER (write); nunca ADMIN
    scopes: frozenset[str]  # para usuário: {"ingest","read","write"} conforme o papel
def require(min_role: Role = Role.VIEWER, *, scope: str | None = None) -> Callable[..., Principal]: ...
```

`current_project_id` permanece como atalho de compatibilidade (`require(Role.VIEWER)` → `project_id`) até todos os routers migrarem; ao final do G0 nenhum router o usa.

### Endpoints de autenticação

- `POST /api/v1/auth/login` `{email, password}` → `200 {token, expires_at, user: User, memberships: Membership[]}`; `401` genérico; `429` com `Retry-After` após falhas repetidas.
- `POST /api/v1/auth/logout` → `204` (revoga a sessão atual).
- `GET /api/v1/auth/me` → `{user: User, memberships: Membership[]}`.
- `POST /api/v1/auth/password` `{current_password, new_password}` → `204`; revoga as outras sessões. Senha: mínimo 12 caracteres, máximo 256.
- `GET /api/v1/auth/sessions` → sessões ativas do usuário; `DELETE /api/v1/auth/sessions/{id}`.

```ts
type Role = "viewer"|"member"|"admin"|"owner";
type User = { id: string; email: string; name: string; created_at: string; last_login_at: string|null };
type Membership = { project: {id: string; name: string}; role: Role };
```

### Projetos, membros, chaves

- `GET /api/v1/projects` → `{items: Membership[]}` (do usuário). `POST /api/v1/projects` `{name}` → `201 {project, role: "owner"}` (controlado por `MATRIX_ALLOW_PROJECT_CREATION`, padrão `true`). `DELETE /api/v1/projects/{id}` (owner) → `204`, apaga dados relacionais e agenda remoção dos spans.
- `GET /api/v1/projects/{id}/members` → `{items: {user: User, role: Role, added_at}[]}` (admin). `POST` `{email, role}` (usuário precisa existir; `409` se já membro) · `PATCH /{user_id}` `{role}` · `DELETE /{user_id}` (não remove o último owner; admin não mexe em owner).
- `GET /api/v1/projects/{id}/keys` → `{items: {id, prefix, name, scopes, created_at, last_used_at, revoked_at}[]}` · `POST` `{name, scopes}` → `201 {id, prefix, api_key}` (segredo só nesta resposta) · `DELETE /{key_id}` revoga. Todos admin.
- `GET/POST/DELETE /api/v1/projects/{id}/egress-hosts` (admin): `{items: {id, host, created_at, created_by}[]}`; `POST {host}` aceita `exemplo.com` ou `*.exemplo.com`; rejeita IP literal, `localhost`, curinga solto.

### Plataforma (token de admin da plataforma, `MATRIX_ADMIN_TOKEN`)

`POST /api/v1/admin/users` `{email, name, password}` → `201 User` · `POST /api/v1/admin/projects` (já existe; passa a aceitar `owner_email?` e a criar a chave inicial com os três escopos) · CLI `matrix-admin create-user|create-project|add-member`.

### Auditoria

`GET /api/v1/projects/{id}/audit-log?limit&cursor&action` (admin) → `{items: {id, ts, actor: {kind, id}, action, target, detail}[], next_cursor}`. Ações mínimas: `auth.login`, `auth.login_failed`, `auth.logout`, `member.add|update|remove`, `key.create|revoke`, `project.create|delete`, `egress.host_add|host_remove`, `egress.request`, `artifact.delete`. `detail` nunca contém segredos, corpo de requisição ou senha.

### Modelo de dados (nomes de tabela)

`users`, `memberships(user_id, project_id, role)` único por par, `web_sessions(id = sha256 do token, user_id, created_at, last_seen_at, expires_at, revoked_at, user_agent, ip)`, `login_attempts(key, window_start, count, locked_until)`, `api_keys` ganha `name`, `scopes` (JSON), `created_by`; `audit_log`, `egress_hosts(project_id, host)` único por par.

## 2. Artifact store

```python
# matrix_server/artifacts/__init__.py
class ArtifactStore(Protocol):
    def put(self, project_id: str, stream: BinaryIO, *, max_bytes: int) -> BlobInfo: ...   # sha256, size; calcula hash enquanto grava
    def open(self, project_id: str, sha256: str) -> BinaryIO: ...
    def exists(self, project_id: str, sha256: str) -> bool: ...
    def delete(self, project_id: str, sha256: str) -> None: ...
    def presign_put(self, project_id: str, sha256: str, size: int, ttl: int) -> PresignedRequest | None: ...  # None no backend local
    def presign_get(self, project_id: str, sha256: str, ttl: int, *, filename: str, media_type: str) -> PresignedRequest | None: ...
def build_artifact_store(settings) -> ArtifactStore
```

Configuração: `MATRIX_ARTIFACT_BACKEND=local|s3` (padrão `local`), `MATRIX_ARTIFACT_LOCAL_DIR`, `MATRIX_S3_ENDPOINT`, `MATRIX_S3_BUCKET`, `MATRIX_S3_REGION`, `MATRIX_S3_ACCESS_KEY`, `MATRIX_S3_SECRET_KEY`, `MATRIX_S3_PUBLIC_ENDPOINT` (endereço que o navegador/SDK enxerga, se diferente), `MATRIX_MAX_ARTIFACT_BYTES` (padrão 5 GiB), `MATRIX_PROJECT_QUOTA_BYTES` (padrão 50 GiB), `MATRIX_VERIFY_HASH_MAX_BYTES` (padrão 256 MiB).

```ts
type Artifact = { id: string; name: string; media_type: string; size: number; sha256: string;
  verified: boolean; owner_kind: string|null; owner_id: string|null; created_at: string; created_by: string|null };
```

- `POST /api/v1/artifacts` — upload direto: corpo bruto, cabeçalhos `X-Filename` (obrigatório), `Content-Type`, `X-Owner-Kind?`, `X-Owner-Id?`, `X-Sha256?` (se enviado, é conferido: `422` se divergir) → `201 Artifact`. Faz stream; respeita `MATRIX_MAX_ARTIFACT_BYTES` e a cota (`413`). Member.
- `POST /api/v1/artifacts/uploads` `{filename, size, sha256, media_type, owner_kind?, owner_id?}` → `201 {artifact: Artifact (verified=false, status "pending"), upload: {method, url, headers, expires_at}}`; backend local devolve `url` apontando para `PUT /api/v1/artifacts/{id}/content`. `POST /api/v1/artifacts/{id}/complete` → confere tamanho e (até o limite) o hash → `200 Artifact`; falha → `422` e o objeto é removido. Member.
- `GET /api/v1/artifacts?owner_kind&owner_id&limit&cursor` · `GET /api/v1/artifacts/{id}` → `Artifact` · `GET /api/v1/artifacts/{id}/download` → `200` com o conteúdo (backend local) ou `302` para URL pré-assinada (S3), sempre `attachment` + `nosniff`; `?inline=1` só para tipos de imagem da allowlist, com CSP `sandbox`. Viewer.
- `DELETE /api/v1/artifacts/{id}` → `204` (member); o blob só sai no GC. Job `artifacts.gc` remove blobs sem referência (e uploads pendentes expirados).
- Nome de arquivo: normalizado (sem separadores de caminho, sem caracteres de controle, máx. 255); nunca usado em caminho de disco nem chave S3.
- Tabela `artifacts(id, project_id, name, media_type, size, sha256, verified, status pending|ready, owner_kind, owner_id, created_by, created_at)`.

## 3. Política de saída (`matrix_server.egress`)

```python
@dataclass(frozen=True)
class EgressTarget: url: str; host: str; ip: str; port: int
class EgressError(Exception): ...  # mensagem segura, sem URL completa com query
def check_url(url: str, *, project_id: str, session: Session, purpose: str) -> EgressTarget
def egress_client(*, project_id, session_factory, purpose, timeout=10.0, max_response_bytes=1_000_000, max_redirects=3) -> "EgressClient"
class EgressClient:
    def request(self, method: str, url: str, *, headers=None, content: bytes|None=None, json=None) -> EgressResponse  # revalida cada salto, fixa IP, limita tamanho
```

Regras e configuração: ADR-012 (`MATRIX_EGRESS_MODE=allowlist|public`, `MATRIX_EGRESS_ALLOW_PRIVATE`, `MATRIX_EGRESS_ALLOWED_PORTS`). Todo uso grava `audit_log` (`egress.request`). Fatias futuras (webhooks, scanner, runner) **só** chamam `egress_client(...)`.

## 4. Web

- Rotas: `/login`, `/settings` (perfil e senha), `/settings/members`, `/settings/keys`, `/settings/egress`, `/settings/audit`. Seletor de projeto na barra lateral; itens e botões escondidos conforme o papel (a API continua sendo a barreira).
- O servidor Next guarda `{token, project_id}` em cookie HttpOnly e injeta `Authorization`/`X-Matrix-Project` no proxy (`/api/proxy/*`) e nos Server Components; `middleware.ts` redireciona para `/login` sem sessão. O `MATRIX_API_KEY` global do ciclo 1 deixa de ser usado (continua aceito apenas em `MATRIX_MOCK=1`).
- Estados de carregamento: reintroduzir com `<Suspense>` por seção (não `loading.tsx` de rota) ou corrigir a causa; critério: clicar em span/aba/poller com latência de 300 ms sempre atualiza a página.
